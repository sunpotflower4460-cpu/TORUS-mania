## 1. 問いを小さくしすぎない

本研究の出発点は、次の強い仮説である。

> 波・陰陽・渦・砂時計・木の根と枝葉は、一つの動的な仕組みの異なる現れではないか。
> 単体のトーラスと、それらの相互作用・入れ子・結合によって、世界を記述できるのではないか。

「見た目の比喩として面白い」で終わらせない。
実在する運動・生成過程・相互作用の共通性があるかを調べる。
同時に、似た図を並べただけで同じ原因を認めることもしない。
仮説を変更するときは、元の命題、変更理由、残った命題を記録する。
強い命題が支持されなかったことを、弱い命題への言い換えで隠さない。

## 2. 判定する命題を分ける

| ID | 命題 | 支持に必要なもの | 支持できない例 |
|---|---|---|---|
| H-P | 同じ運動から、波・渦状・砂時計状の複数の見え方が得られる | 同一状態から固定した観測写像で再現 | 別々の画像を手で似せる |
| H-R | 定義済みのトーラス構造が、多数の自然現象で繰り返し現れる | 分母を持つ事例調査と対照比較 | トーラスがある例だけ集める |
| H-U | 対象範囲の全現象に、トーラスが必要である | 明確な「必要」の定義、反例探索、モデル上の必要条件 | 有名な成功例を多数列挙する |
| H-G | 一つの生成則から複数分野の構造が生まれる | 方程式・変数の対応・境界条件・未見予測 | 分野ごとに別の生成器を呼ぶ |
| H-I | トーラス間の相互作用から複雑なまとまりが生まれる | 結合介入、無結合対照、因果的な予測 | 外部から決めた振付どおりに動く |
| H-C | 宇宙全体がトーラス状の流れ・相互作用として記述できる | 具体的な動的宇宙モデルと観測予測 | 局所の煙の輪、位相空間の輪 |

H-R の成功は H-U の証明ではない。
H-P の成功だけでは H-G、H-I、H-C を支持できない。
有限の観測事例から「全宇宙の全現象」を証明することはできない。
H-U はまず、対象・尺度・時間幅を限定した検証可能な命題として扱う。
限定前の普遍命題は、未解決の上位仮説として残す。

### 「必要」の意味を登録する

次のうち、どれを主張しているかを先に選ぶ。

1. 対象の物理構造に、検出可能なトーラスが存在する。
2. 対象を記述する状態空間に、トーラスが存在する。
3. 現象を生成する仕組みに、トーラス状の循環が不可欠である。
4. 他の構造を使う説明より、トーラスを使う説明の予測力が高い。

これらを結果に応じて入れ替えない。
「必要条件」の反証には、条件を満たさないのに現象が起きる例が有効である。
「よりよい説明」の判定には、代替モデルとの比較が必要である。

## 3. 「何をトーラスと呼ぶか」を固定する

| 対象 | 操作的な意味 | 混同しない対象 |
|---|---|---|
| 幾何学的なトーラス表面 | 実空間内の、通常はドーナツ状の二次元表面 T² | ドーナツの中身を含む立体 |
| ソリッドトーラス | 円板 × 円周で表される三次元の管状領域 | 二つの独立な穴を持つ物体 |
| 位相状態空間の T² | 二つの周期位相の組 S¹ × S¹ | 身体・場がドーナツ形という主張 |
| トーラス状の渦度領域 | 渦度の集中領域が輪を作る | 流体粒子が全員閉じた輪を回ること |
| トーラス状の磁気面 | 磁力線が沿う面がトーラスとして記述できる | 各磁力線や粒子軌道が閉じること |
| 空間の三次元トーラス T³ | 三つの空間方向の周期的な同一視 | 外側から見た穴付きドーナツ宇宙 |

数学上の定義と、測定データから判定する方法を別欄に記録する。
渦、循環、輪、周期性、トーラスは、互いに関連しても同義語ではない。

### 3.1 普通のトーラス、砂時計、双曲面

標準的なリングトーラスは、R > r > 0 として次のように表せる。

```text
x = (R + r cos θ) cos φ
y = (R + r cos θ) sin φ
z = r sin θ
```

中心軸上に表面はなく、全経路が一つの中心点を通るわけではない。
R = r の接触した形、R < r の自己交差を伴う表現は、別条件として扱う。
通常の滑らかなリングトーラスと同じ物体として集計しない。

一葉双曲面 x²/a² + y²/b² − z²/c² = 1 は、中央がくびれた非コンパクトな面である。
上下の円錐が頂点で接する図とも、閉じたトーラスとも異なる。
「砂時計に見える」は画像特徴であり、それだけで位相や運動は決まらない。
任意のくびれを、結果を見てからトーラスへ分類し直さない。

### 3.2 正弦波との対応

一様な円運動の一座標は A sin(ωt + φ₀) と書ける。
その座標を時間に対して描くと正弦波になる。
円を単に横から見るだけなら、通常は線分や楕円である。
回転に一定速度の並進を足した螺旋では、空間投影も正弦波になり得る。

トーラス上で θ が一定角速度なら z(t) は正弦波になる。
他の座標は二つの角度を混ぜるため、一般に単一正弦波とは限らない。
波形の一致、座標表示の同値性、同じ物理過程による生成を分けて判定する。

## 4. 線の意味を取り違えない

| 表示 | 定義 | 読み取れるもの |
|---|---|---|
| 流線 | 時刻 t₀ の速度場 u(x,t₀) に接する曲線 | その瞬間の流れの向き |
| 粒子軌跡 | dx/dt = u(x,t) の解 | 一つの粒子の時間的な移動 |
| 渦線 | 渦度 ∇×u に接する曲線 | 局所的な回転の配置 |
| 磁力線 | 磁場 B に接する曲線 | その瞬間の磁場の向き |
| 境界・等値面 | 物体境界や、ある量の一定値の面 | 領域の形や分布 |
| 状態空間軌道 | 位置以外も含む状態の時間発展 | 系の状態間の関係 |

非定常な流れでは、流線と粒子軌跡は一般に一致しない。
磁力線を荷電粒子の軌道として描かない。
可視化には、表示対象、時刻、線の追跡条件、閾値、座標系を添える。
「台風の目に似た静かな中心」は、圧力・速度・渦度のどの特徴かを測る。
中心が低速でも、そこが物質の出入口や特別な宇宙の中心とは限らない。

## 5. 陰陽・中心・木を測定可能にする

### 陰陽

「二つの反対の働きが、全体の中で互いを成立させる」という仮説を維持する。
その具体化として、流入／流出、上昇／下降、相対位相、相互抑制などを検討する。
実験ごとに一つを主指標とし、正負の定義と観測軸を事前登録する。
色を二色にしたこと、座標の符号を分けたこと自体は証拠に数えない。
向きや色を変えても残る関係と、表示だけで生まれる関係を区別する。

### 中心

幾何学的中心、流れの停滞点、回転軸、物質の供給源、観測者の位置を分ける。
中心をどの式・測定で定義したか記録する。
相対論の光円錐の頂点は特定の出来事であり、空間の渦の中心ではない。
光円錐の上下は時間と因果関係の範囲を表す。[P1]

### 木の根・幹・枝葉

根と枝葉の二方向への展開、資源輸送、相互依存を別々に測る。
根と茎の重力応答には、同じオーキシン信号への異なる細胞応答が関わる。[P2]
形の分岐を調べるときは、節点・枝・分岐角・太さ・長さを記録する。
輸送を調べるときは、供給源、消費先、物質の種類、圧力差、流量を記録する。

木部の水輸送と師部の糖輸送は、一つの同じ物質の閉じた上下循環ではない。
糖は供給源から消費・貯蔵先へ移り、供給源の位置は季節や成長状態で変わる。[P3]
生理機能の相互依存によるループと、物質が戻る閉路を別の図にする。
木の成長を共通生成則から出せるかは、分岐を最初から与えずに調べる。

## 6. 二周期・準周期運動の厳密さと限界

二つの位相を θ₁, θ₂ とすれば、その組を T² として表せる。
独立な等速回転では、周波数比が有理数なら軌道は周期的に閉じる。
無理数比なら理想的な連続時間・無限精度のモデルでは同じ状態へ完全には戻らない。
このモデルの軌道は T² 上で稠密になるが、有限時間で面全体を埋めるわけではない。
二つの位相の状態空間が T² でも、一本の周期軌道自体が T² になるわけではない。

測定した有限小数から、現実の比が数学的に無理数だと証明することはできない。
浮動小数点計算と離散サンプリングでは、有限精度・エイリアシング・長周期を考慮する。
「戻らなかった」は、記録した時間幅と許容誤差を伴う記述に限定する。
結合によって位相同期すれば、二つの振動子でも実効的な運動が一周期になる場合がある。
位相円を最初から二つ置いた実験は、位相トーラスを発見した実験ではない。

## 7. 生成と、あらかじめ与えた条件

各実験で次の由来を記録する。

| 項目 | 記録内容 |
|---|---|
| 計算領域 | 周期境界、壁、流入流出、領域サイズ |
| 初期状態 | トーラス・輪・対称性を初期値に置いたか |
| 外力・装置 | 円形ノズル、回転、周期駆動、二極性を与えたか |
| 方程式 | トーラスへの誘導項や形状目標を含むか |
| 観測器 | トーラスだけを拾う閾値・投影になっていないか |

「周期境界で戻る」は、境界を周期的にした結果である可能性をまず調べる。
円形ノズルから渦輪ができることは物理的な生成だが、幾何学的な誘導も受けている。
何も与えないことを自発性の条件にせず、どの条件を与え、どの秩序が未指定だったかを示す。
同じ則で境界・形・初期状態を変え、生成する範囲と生成しない範囲を両方求める。
渦輪形成の実験研究には、流量・ストローク・ノズル条件を変えた例がある。[P4]

## 8. 保存則と収支を先に確認する

候補モデルの一つとして、非圧縮流体では次の系を使える。

```text
∂t u + (u·∇)u = −∇p/ρ + ν∇²u + f
∇·u = 0
```

これは流体のモデルであり、これを使っただけで植物・電磁場・宇宙が統一されるわけではない。[P5]
物質 q を運ぶなら、輸送・拡散・生成消滅を含む収支も定義する。

```text
∂t q + ∇·(q u) = ∇·(D∇q) + S
```

モデルごとに質量、運動量、エネルギー、角運動量、循環等の収支を選ぶ。
保存される条件、外部からの供給、境界からの流出、粘性による散逸を明記する。
粘性・外力・開放境界のある実験で、全ての量を保存するよう要求しない。
ヘリシティや循環の保存を使う場合は、流体の理想化と境界条件を別途確認する。
数値誤差で生まれた増幅を、自己維持やエネルギー生成と解釈しない。
「循環があるから永久に保たれる」という推論は使わない。

## 9. 分母・対照・反例を設計する

### 9.1 出現頻度の分母

最初に、対象分野、採択基準、観測尺度、情報源、抽出手順を固定する。
「トーラス」で検索した事例集は、存在例の収集として扱う。
頻度の推定には、現象名や分野名から集めた独立の標本群を別に用意する。
同じ映像の転載、同じ研究の再紹介、同じ試料の複数画像は重複として数える。
未観測・解像度不足・アクセス不能を「なし」にしない。欠測として報告する。
分野ごとの頻度と、抽出の偏りを示す。全自然現象への割合へ外挿しない。

### 9.2 流れに基づく帰無モデル

| 対象 | 必須の対照例 | 揃える条件 |
|---|---|---|
| 流体 | 一方向流、せん断流、回転流、非圧縮ランダム場 | 境界、解像度、エネルギーや流量の尺度 |
| 振動 | 一周期、同期二周期、非同期二周期、ノイズ | 記録長、サンプリング、スペクトル条件 |
| 輸送網 | 木だけの網、閉路付き網、生成した一般の網 | 供給消費、総材料量、輸送量、コスト |
| 観測画像 | 円柱、球、双曲面、二円錐、既知トーラス | 視点、ノイズ、遮蔽、点数 |
| 相互作用 | 無結合、片方向結合、共有外力のみ | 初期分布、駆動、観測時間 |

ランダム場も、対象に応じた発散条件・境界条件を満たすものを使う。
グラフをシャッフルしたら、連結性と供給消費の整合性を再確認する。
見た目だけを乱した、物理的に不可能な対照を唯一の比較対象にしない。
制約を揃えすぎて答えまで固定しない。何を保存した帰無モデルか列記する。

## 10. 検出と統計

トーラス判定は、画像の印象、幾何学的適合、位相、力学の四段階で記録する。
画像のみの判定は暫定とし、三次元データや運動データで確認する。
位相解析では、T² 表面とソリッドトーラスの次元・穴の数を混同しない。
ベッチ数などが一致するだけでは、物体や生成機構の同一性は証明できない。
閾値・平滑化・点密度を変えたときに残る特徴を確認する。
検出器の偽陽性率を、既知の非トーラス対照で先に測る。

主評価量、許容誤差、試行数、失敗条件は評価用データを見る前に固定する。
探索用データで閾値を調整したら、未使用の評価用データで判定する。
数値試行では乱数種、時間刻み、格子、収束確認の結果を残す。
効果量・不確かさ・試行数を報告し、有意／非有意だけに要約しない。
画像から選んだ最も美しい一回を、代表的な成功として使わない。
複数の指標を試した場合は全指標を記録し、探索と確認を分ける。

## 11. 同じ方程式が複数分野を説明したと言える条件

1. 状態変数の物理的意味・単位・観測方法が各分野で定義されている。
2. 方程式の形と相互作用則が共通で、分野ごとの隠れた生成器がない。
3. 変えてよいパラメータ・境界・尺度変換の範囲を事前に決めている。
4. 一つの分野で合わせた後、別分野の未使用データに予測を出している。
5. 形に加え、時間変化・介入応答・壊れる条件の少なくとも一つを予測する。
6. 分野固有モデル、単純な輸送モデル、トーラスを仮定しないモデルと比較する。
7. 適合の良さとモデルの自由度・計算量を併記する。

共通する数式の形だけなら「同じ有効モデルの候補」と報告する。
実在する同一機構まで主張するには、変数と因果的介入の対応も要る。
同じ基礎式でも境界条件が違えば形は異なる。この差も予測対象にする。
分野別の追加項が必要なら、その項を明示し、統一の範囲を狭めて再評価する。
生物の分岐には、共通性と分野固有の差の双方を調べた一次研究がある。[P6]

## 12. 因果・反証・中止の規則

共通の外力で二つが同時に動いた場合を、直接の相互作用と取り違えない。
結合を切る、位相をずらす、供給を変える、境界を変える介入で予測を比べる。
介入前の予測を保存し、結果を見てから説明を作り替えない。
反例が出たら、測定誤差、対象外、仮説の失敗のどれかを根拠とともに記録する。
「別の尺度ならトーラスがあるはず」は、尺度を事前指定しない限り救済に使わない。

次の場合は、その試行を止め、原因確認へ戻る。

- 収支・数値安定性・境界条件の検証に失敗した。
- 判定閾値を変えないと結果を維持できない。
- 予定した計算・取得予算を超えた。
- 必要な観測量がなく、似た形以上の判定ができない。

H-U の反例が見つかっても、H-R や H-G を自動的に棄却しない。
逆に H-R が成功しても、H-U の反例を無視しない。

## 13. 宇宙への接続と適用限界

正式主張 H10 は宇宙の動的な流れ・相互作用を問う。空間の T³ という仮説とは別に定式化する。
宇宙 T³ は、空間のつながり方に関する仮説である。
局所の渦輪、物体の形、位相空間 T² の結果から直接は結論できない。
Planck の研究は特定の多重連結空間を検証し、調べた尺度で証拠を見いだしていない。[P7]
この制約を「全てのトーラス宇宙が否定された」とも「トーラス宇宙が確認された」とも書かない。
T³ の制約や将来の検出を、そのまま H10 の採否に転用しない。両モデルの予測の対応が別途必要である。
新モデルを検証するには、背景放射の相関など観測可能量を具体的に予測する必要がある。
宇宙論の数値解析は、流体の可視化デモから切り離した別段階とする。

## 14. 継続担当者の作業契約

実験前に、対応命題・変数・対照・主評価量・停止条件を短い登録票に書く。
実行後は、設定、コード版、入力の出典、全試行の一覧、失敗も含む結果を残す。
実行の進捗は「未実施／探索／確認」等で表示し、主張の判定とは分ける。
主張の判定は正式IDごとに、02の判定語と claims.json の形式に従って記録する。
次に行う作業は、最大の未解決点を一つ減らすものから選ぶ。
既存の結果を「たぶん成功」とみなして飛ばさず、実物の記録を読んで引き継ぐ。
可視化の美しさ、再現性、物理的妥当性、仮説への証拠を別々に評価する。
実験の具体的な順序・入出力は [05_EXPERIMENT_PLAN.md](05_EXPERIMENT_PLAN.md) に従う。
