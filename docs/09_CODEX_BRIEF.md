# Codexへの研究依頼 — TORUS-mania

対象リポジトリ：
https://github.com/sunpotflower4460-cpu/TORUS-mania.git

開始資料の準備日：2026-11-20（Asia/Tokyo）

## あなたへの依頼

このリポジトリを引き継ぎ、**「トーラスが至るところに存在する共通原理と言えるかどうか」**を、文献、数学、観測、再現可能な計算実験によって調べてください。

結論を先に決めないでください。肯定するための図集にも、否定するための一般論にもせず、どの意味で成立し得るのか、どこに限界があるのかを具体的に明らかにしてください。

## 発案者の考えを正確に受け取る

出発点は、「トーラス、陰陽、渦、砂時計状の中心、台風の目、正弦波を、同じひとつの動的な仕組みの異なる見方として捉えられるのではないか」という直感です。

単体としてはトーラスのような循環であり、それぞれのまとまり同士が関わり、その関係全体が世界や宇宙を形づくっているのではないか。木が根と枝葉の両側へ伸びる姿も、この基本的な仕組みの現れではないか、と考えています。

「ひとつのものをいろんな方向から見ているだけなのでは？」という問いが中心です。外形がドーナツに似ているかという話に縮めないでください。

同時に、「共通の仕組み」を単に「すべては関係している」という一般論へ広げて、トーラスという仮説を検証済みにしないでください。

## Phase 0 — 現在地とアクセスの確認

- 現在のブランチ・未コミット変更・追加の研究成果を確認し、他の作業を保護する。
- READMEと既存の記録を読み、準備済みのことを再度作り直さない。
- Python、使える数値ライブラリ、CPU・メモリ、ネットワーク、ブラウズ・動画確認能力を個別に記録する。
- `python3 scripts/research_access.py --help` と `list` を実行し、資料索引が読めるか確かめる。
- このチャットで利用できたサービスが、引継ぎ先にもあるとは仮定しない。
- 公開資料へ到達できなければ原因を記録し、索引・抄録・既存カード・オフライン実験で進められる部分を進める。

## Phase 1 — 主張を測定できる形へする

「頻繁に現れる」「同じ原理で生成される」「全現象に必要である」を別々に扱う。各主張について、次を埋める。

- 対象と尺度
- トーラスなのは何か（実空間の領域／表面／流線／軌道／状態空間／宇宙の空間）
- 観測・投影・断面・時間記録の方法
- 何があれば支持が強まり、何があれば弱まるか
- 別の説明との区別
- 測定できない場合は、何が足りないか

共通原理の候補を勝手に一本化せず、「トーラス的循環が基本」という元の仮説と、「さらに下位の原理からトーラスも他の形も生まれる」という代替を、比較できる形で残す。

## Phase 2 — 一次資料を精読し、証拠地図をつくる

資料索引から優先度の高いものを読み、`research/notes/` に短い文献カードをつくる。

最低限、回転の投影、複数周期、流体の渦輪、磁場、生物の分岐・輸送、宇宙のトポロジーを扱う。同じ条件で、球面、単純な閉曲線、樹状構造、非周期的・カオス的な系なども比較対象に含める。

論文の「報告」と自分たちの「再現」を区別する。全文を読んでいないときは抄録確認と明記する。データ・コードを得たときは、公開元、版、利用条件、取得日を残す。

動画では、図や映像の一次出典を追跡する。動画で図が並べられていることを、同じ原因の証拠にしない。動画の宗教的・精神的解釈を、発案者自身が採用していると決めつけない。

## Phase 3 — 最初の実験を実装して動かす

`docs/05_EXPERIMENT_PLAN.md` のE01から進める。まずE01とE02を実装・実行し、計画だけで終わらない。

E01では、同じ動きの3D表示・空間投影・時間記録を対応づける。E02では、二つの周期の状態空間と実際の軌道を分ける。整数比・無理数比の近似・同期・雑音・有限時間の違いを確認する。

正解の分かる例と、正解がトーラスではない例を同じ測定器に通す。きれいな図ができたことを成功条件にしない。解析式に対応する数値と、どの仮定を入れたかを残す。

依存追加は必要なものだけにする。小さなパイロット計算から始め、CPU時間・メモリを記録し、結果の不確実性を減らす必要があるときに計算を増やす。

## Phase 4 — 物理の渦、分岐、相互作用へ進める

E01・E02の校正後、E03以降を順に進める。

- 実在する物理モデルの渦を、任意の曲線アニメーションと分ける。
- トーラス状初期条件を与えた試験と、与えない試験を分ける。
- 周期境界を外したとき、同じ構造・機能が残るか調べる。
- 分岐と循環を同じものと宣言せず、共通のルールから双方が出る条件を調べる。
- 複数のまとまりの相互作用は、持続性・交換・摂動への応答で測る。生命や意識の成立は別の仮説とする。
- 同じモデルを別分野へ使うなら、各分野の量の対応と予測を明示する。

一つのモデルで失敗しても普遍的否定にしない。成功しても自然界一般の実証にしない。どの条件が結果を分けたかを記録する。

## Phase 5 — 中間結論と次の研究

最終的には少なくとも以下を残す。

1. `research/STATUS.md`：完了・未完了・次の作業・再開コマンド
2. `docs/10_FIRST_RESEARCH_REPORT.md`：一般向け説明と技術的根拠
3. `research/claims.json` の根拠付き更新
4. `research/notes/` の文献カード
5. 実験コード、実行条件、乱数種、結果、対照、必要な図
6. 成立条件と反例、別の説明、判断できなかった点
7. 次に何を見れば仮説同士を区別できるか

結論は「トーラスがある／ない」の二択に押し込めず、**どの対象に、どの意味で、どんな条件なら現れるか**を示してください。

## 自律進行の範囲

この依頼内の読み取り・無料の公開調査・実験・修正・記録は、通常の細部ごとに確認を求めず進めてください。実行枠が尽きるときは、再現可能な中間状態を保存してください。

有料サービスを新規購入したり、外部へ連絡したり、アクセス制御を回避したりする必要はありません。大規模な計算が必要なら、先に小さな結果と費用・利点を具体化してください。

変更は意味のある単位でコミットし、既存のリポジトリ方針に従って共有してください。文章だけで完了とせず、可能な実験まで進めてください。

## 最終的に知りたいこと

**トーラスは、自然界にたびたび現れる便利な形なのか。複数の現象をつなぐ数学的な構造なのか。現実の多様な形を生み出す共通の動的原理なのか。それとも、これらが条件ごとに異なるのか。**

発案者の直感を、その問いが本当に確かめられるところまで育ててください。
