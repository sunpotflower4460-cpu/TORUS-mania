## 2. 会話からの重要な補正

### 「横から見ると波」の意味

円の軌道を真横から投影すれば線分になる。点の一座標を時間に沿って並べれば正弦波になる。一定速度で進む螺旋の横投影なら、空間の正弦波になることがある。時間軸と空間軸を取り違えない。

### 「中心」の意味

幾何学上の軸、流速が小さい領域、流れの停滞点、渦度の集中域、観測者の「ここ・今」、宇宙全体の特別な地点は別。どれを測定するかを指定する。

### 「戻る」の意味

同じ粒子が戻る、物質の流束が閉じる、位相が戻る、状態が近くなる、影響が他を経由して返る、は同じではない。根と葉の相互依存を物質の閉軌道と混同しない。

### 「同じ形」の意味

輪郭一致・断面一致・位相同型・同じ方程式・同じ原因は強さが異なる。変形や投影の自由度が大きすぎれば、何でも対応してしまい、予測力がなくなる。

## 3. 結論の強さを上げるには

| 次に知りたいこと | 必要な作業 |
|---|---|
| 見た目の偶然以上の対応か | 観測写像を先に固定し、非トーラス対照にも同じ方法を適用 |
| 本当に同じ生成機構か | 同じモデルを使い、対象ごとの自由な後付けを制限 |
| トーラスが原因か、結果か | 条件や結合を変え、トーラス性と機能が一緒に変わるか測定 |
| 自然に生じたのか | トーラスを初期条件・周期境界・座標に与えた条件と分ける |
| 分野を越えた原理か | 学習／調整に使っていない対象への予測を評価 |
| 普遍的なのか | 対象範囲を固定し、非トーラスの成立例と必要条件を調べる |

## 4. 現段階の判定

H01・H02には基準となる数学があり、トーラス的な構造が実際に重要になる個別分野の資料もある。しかし、H05〜H10の大きな統一仮説をこの準備で実証したわけではない。
