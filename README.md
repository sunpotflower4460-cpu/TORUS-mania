# TORUS-mania

**トーラスは、至るところに現れる共通原理と言えるのか。**

同じ動的な仕組みを異なる方向・断面・時間幅・尺度から見ることで、波、渦、陰陽的な対、砂時計状の中心、樹木の根と枝葉などが現れるのではないか。単体はトーラス的な循環であり、それらの関係がさらに大きな世界を形づくるのではないか。

このリポジトリは、その問いを、定義・一次資料・比較・再現可能な実験へつなぐ研究拠点です。結論を先に決めず、仮説の強い意味を保ったまま、どこまで支持できるかを調べます。

## 現在の研究結果

E01〜E54を実行した。線虫の1細胞胚では、流れで極性の目印を回すと、次の分裂で小さい娘細胞ができる側を反転できた。90度未満の9個は元の向き、90度超の3個は反対向きに分裂した。自然な受精卵でも、精子由来の複合体が流れで動いた後の位置から、後端の側を予測できた。植物では、オーキシン輸送の2方向を別々に弱められ、側根への供給と伸長が変わった。同じ天然IAA分子の根での一周、身体の形成を先導する全機械エネルギーの三次元トーラス状の経路、自然界全体での普遍性は未判定。[第14回研究報告](docs/23_TURNING_PATHS_AND_AXIS_REPORT.md)・[主張台帳](research/claims.json)・[再開と追試](research/STATUS.md)

## 最初の研究結果

E01・E02を実行した。円運動と直線振動は同じ正弦波を与え、長周期の閉軌道は二位相の観測方眼を全区画訪れた。観測から識別できた範囲、分野横断の生成仮説に残る問い、再実行の手順を公開している。[第1回研究報告](docs/10_FIRST_RESEARCH_REPORT.md)・[再開メモ](research/STATUS.md)

## この準備段階で分かっていること

- 円運動の一座標を時間に沿って記録すると正弦波になる、など、条件を明示すれば厳密な対応がある。
- 実空間のトーラス状構造、状態空間のトーラス、宇宙空間のトポロジーは、同じ言葉でも対象が違う。
- 渦・磁場・複数周期などの個別例を確認することと、自然界全体の共通生成原理を実証することは別の段階。
- 準備時に整備した資料・設計・アクセス補助を用いて、現在は渦・輸送・相互作用の物理計算と公開植物データの再集計まで進んだ。動的宇宙仮説は未判定。

根拠と適用条件は[根拠台帳](docs/03_EVIDENCE_LEDGER.md)を参照。

## 作業の原則

着想を尊重し、根拠を増やす。支持例だけを集めず、同じ条件で別の構造も調べる。見た目・数学的表現・生成機構・観測を取り違えない。分からないことは、何を調べれば進めるかと一緒に残す。
