# E62　全胚の三次元座標で、追跡した細胞の初回帰還を探す

2026-11-20 UTC。Shahらの著者ビューアの original と bundled の二状態、BiohubのVirtual Embryo Zooの疎行列形式を確認した。座標の転帰を採点する前に登録した。[Shahら](https://doi.org/10.1038/s41467-019-13625-0)・[Biohubのゼブラフィッシュ](https://virtual-embryo-zoo.sf.czbiohub.org/dataset/danior)

- Shahらの原著が記載する、短い追跡から統計的速度場でつないだ軌跡は、一個の細胞の同定から除く。ビューアの original がその連結前であると確認できる場合にだけ一次の採点に入れる。ビューアで束ねた形も一次には加えない。Biohubの画像を追跡して得た枝IDが連続するフレームを一次とする。分裂の異なるIDを一つの観測として結合しない。データの書式と由来が確認できない場合は採点を保留する。
- 解析単位は一つの連続した追跡区間。はじめの位置から広がり尺度の0.02以上離れ、観測経路が尺度の0.05以上で、10観測以上連続し、その位置から尺度の0.005以内に戻った最初の区間を一次候補とする。尺度は配布物の全体幅のメタデータ、無い場合は全座標の各軸1–99パーセンタイル幅の最大値。最大の一歩が遠ざかった距離の半分より大きい候補は飛び移りの疑いとして除く。主成分の二次元面へ投影し、経路長に沿って32等区間で再標本化する。第2と第1特異値の比0.15以上、経路中心のまわりの絶対正味角が0.8周以上、総角移動に対する正味角の割合0.75以上をすべて満たすとき、曲がって帰る候補と数える。出発点への直線の付け足しで回転角を稼がない。
- 全ID、枝内の連続区間数、10点と20・40点残る区間数、十分遠ざかる区間、出発付近に戻る候補、形を満たす候補を数える。20点以上と帰還距離の半分・倍で変化を見る。層・空間・時間を合わせた独立胚の頻度推定は行わない。区間の中途から始まるループは主解析の範囲外とし、一次候補数が許せば10観測刻みの出発点でも検査する。
- 合成対照は三次元に傾いた円、一部の欠けた円、直線往復、一方向の弧、同じ投影に戻るが奥行きでは帰還しないらせんとする。いくつかの候補が見つかった場合は、座標の候補までを支持とし、追跡誤り、分裂、全胚の剛体運動、体積像での確認を別途扱う。媒体を構成する細胞質粒子の経路や、機械的なエネルギー流束はこのファイルで判定できない。
