# E28　戻りと細胞生産の待ち時間を比べる

2026-11-20 UTC。E22の三つの区画を利用し、van den Bergら（2021、`10.1016/j.devcel.2021.07.005`）の「戻りによる蓄積域と成長の組合せ」と比べられる最小モデルを作る。細胞分裂や幾何を解く原著の再現とは範囲が異なる。実装と計算前に登録する。

- 1回目に中心へ戻った量だけを数える。根先に置いた単位パルスは、外層、中心の順に通る。中心への到達は吸収端に記録。E22の根先→外層と外層→中心の率は1.00、0.60、局所損失は0.25、0.35。規格化時間を使用。到達量が投入量の0.20に達する時間を輸送の待ち時間τとする。開いた対照では外層は同じ率で外に排出。E22の定常状態の量と二つの前向き流束を対照間で揃え、補充に標識を入れない。
- 順次二つの待ち時間が必要な模型。輸送を待った後に、細胞生産率p（細胞数/規格化時間）でL=2細胞分進むまで待つ。観測式は周期T=τ+L/p、頻度1/T、間隔pT。初回の端効果を避け、9イベントの時間と位置を記録。p=1を合わせた独立供給の定周期対照、定間隔対照、および輸送なしに同じ待ち時間を外から課す対照を置く。最後の対照は周期と間隔を全条件で再現するという反例になる。事前設定した待ち時間と更新規則を明示し、自発的な細胞内発振とは扱わない。
- 登録した成長比は0.5、0.75、1、1.25、1.5。輸送と細胞生産の両方に待ち時間があれば、pを上げると頻度と間隔がともに上がると予測する。帰路の切断と純粋な損失を照合し、初回帰還が0.20に満たない場合はイベント周期を未定義とする。根先・外層の輸送率と損失の共通倍率を各0.75、1、1.25の27通りに変え、判定の安定性を調べる。
- 初回通過の解析式を独立積分器と比較し、パルスの収支を閉じる。生体の時間や流量への換算はせず、実測の比較では別にE29の調整に使った条件を明記する。
