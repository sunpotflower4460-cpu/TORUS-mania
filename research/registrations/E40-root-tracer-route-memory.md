# E40　同じ標識が外層を通り、出発位置へ戻ったと識別する

2026-11-20 UTC。E22の区画モデルで、静止時の量をそろえても外層から中心への接続を変えれば標識の再流入が変わった。今回は、測定場所を増やし全時刻の通常標識量が一致する場合にも通過経路を区別できるかを調べる。

- 中心側の出発点→根端→外層→上側の中心→出発点を候補にする。根端から外層と同じ交換率の別経路へも同量を送り、中心側を供給する枝と損失に向かう枝を二つの模型で入れ替える。総量と通常の標識は全区画・全時刻で一致するという解析結果を数値で確認する。代替の模型は外層を経ない内部経路であり、内部にもループがあり得る。
- 中心側に入れた標識物質を規格化量1とする。規格化時刻1.5に外層の標識の80%に履歴を記録したと仮定する。中心側の出発点にその標識が戻るまでを数える。初回の帰還で計数から除き、何周もした同じ標識を繰り返し数えない。外層と別経路との間で標識の位置に間違いが起きる対照を0%、2%、10%に置く。マーカーの化学的実現と位置選択性は未検証。
- 前向きと帰りの輸送、根端から外層への振り分け、分解の各率で基本値を±25%に変えた81通り。規格化時刻6の初回帰還率を主評価とし、外層の帰路を切る操作では、外層から出る総量を保ち損失へ向ける。未処置・切断・別経路・漏れを比較する。時刻ごとの保存残差と、通常標識の同一性を検査する。
- 観測は投入量に対する帰還割合に平均ゼロの正規雑音を加えた模型。最も弱い帰還と最も大きい偽の帰還を用い、誤検出5%以下かつ感度80%以上を両立する雑音の最大SDを求める。生体の検出下限、標識化学、同じ分子の帰還は実測として未判定。
