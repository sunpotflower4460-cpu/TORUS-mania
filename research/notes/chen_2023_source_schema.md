# Chen2023：公開データの構造と測定単位

確認日：2026-11-22。対象は Chen et al. (2023), *ABCB-mediated shootward auxin transport feeds into the root clock*, [DOI:10.15252/embr.202256271](https://doi.org/10.15252/embr.202256271)。本記録は E79/E80 の原資料監査であり、新しい効果量・P 値・信頼区間の計算結果ではない。原著が報告する振幅低下と周期の非有意差は登録前から既知だった。

## 1. 確認できたこと

出版社の公開リンクから Figure 2、Figure 6 の Excel、Figure 4 と Appendix の source-data ZIP を取得できた。本文は著者所属大学の公開 PDF、補足は出版社の Appendix PDF で確認した。取得元 URL、要求開始時刻、byte 数、SHA-256、ZIP 内各ファイルの hash、対象セル範囲は [機械可読 manifest](../sources/chen2023_manifest.json) に収録した。PDF・Excel・ZIP・全観測値列は Git に含めない。

この資料は、根の外側組織で働く ABCB 群が DR5 の振動へ寄与する機構を調べるのに適している。一方、公開表には周期イベントを根ごとにまとめる ID がなく、振幅・周期・成長・輸送を同じ根に対応させることはできない。**「根の細胞生産を独立に測った状態で、戻り時間だけを変えた実験」には当たらない。**

本文 PDF p5（Fig2）と p10（Fig6）を画像にして目視確認した。周期パネル I/G と振幅パネル J/H の軸、群名、単位は Excel と一致する。周期パネルには振幅より多数の点が描かれている。画像から点を数え直したり、点を根に割り当てたりはしていない。

### 測定定義と時相

本文 PDF p12 の Methods によると、時計の撮影は3日齢、1 mM luciferin、15分間隔、1枚7分露光。Fiji で画素あたりの ADU を求め、後に PBS が生じる位置の正方形 ROI が、その直前の OZ 振動を含むように選ばれている。振幅は OZ 内の最大信号と最小信号の差、周期は DR5:LUC 極大の間隔をフレーム数から求める。

`ADU 15min^-1` は原図・原表の表記を保つ。これは装置の発光読み出しであり、IAA 濃度や物質流量に換算した値ではない。撮影装置は Lumazon FA または NightSHADE LB985 と記されるが、各図への装置割り当て、撮影日別の較正、batch、全個体の撮影総時間は示されていない。Fig2 と Fig6 の WT は独立に表示された比較対照として扱い、両図の絶対振幅差を介入効果や同一 batch の差と解釈しない。

Appendix PDF p6–7 の S4D–F が ROI と trace の実例である。対応する source workbook は `Appendix_Figure_Source_Data/Appendix Figure S4.xlsx`、sheet は `Appendix Figure 4`。時間列は `A29:A104`、PBS 1/2 の信号列は `B29:B104` / `C29:C104` で、0–1125分・15分刻みの76時点を持つ。これは方法を示す単一根の profile の例であり、群間比較用に76根を追加した資料でも、すべての時計個体が18.75時間撮影された証明でもない。

DR5 は auxin 応答の発光レポーターである。Chen2023 が測った極大を、初期の priming 開始、自由 IAA 濃度の極大、同一 IAA 分子の一周時刻と同一視しない。De Gernier2025 の時相に関する留意点は [前回の機構整理](E77_E78_reflux_clock_mechanisms.md) を参照する。一定のレポーター遅延なら周期は保存され得るが、本資料ではその遅延と輸送時間を分離していない。

## 3. E80：方向性輸送と誘導実験

### Fig4A：放射性トレーサーの根端から茎側への輸送

配布ファイルは `abcb_fig4.zip`。ZIP 内は `Figure 4.xlsx` と6枚の CZI ファイル。**Excel の sheet 名は `Figure 4` であり、`4A` は図のパネル番号である。** E80 の登録票にある workbook `4A` という記載はパネルを指すものとして読み、実装は以下の sheet・範囲を使う。この構造訂正のために登録票の内容や byte 列を置き換えない。

`Figure 4.xlsx` の SHA-256 は `66b2fe0db6ac1557cfc3c3f41519758d8aad177477fd7f40bf9d854d751488c6`。

| トレーサー | 群 | 範囲 | 観測値数 | 図説明の n | 単位 |
|---|---|---|---:|---:|---|
| 3H-IAA | Col-0 | `B4:B6` | 3 | 3 | dpm |
| 3H-IAA | amiR-2572 | `C4:C6` | 3 | 3 | dpm |
| 14C-benzoic acid（BA） | Col-0 | `D4:D7` | 4 | 4 | dpm |
| 14C-benzoic acid（BA） | amiR-2572 | `E4:E6` | 3 | 3 | dpm |

本文 PDF p6、Fig4A と説明 p8、および Methods p13 が根拠。本文は根端に外から放射性 IAA を与えたことを記す。Methods は根の shootward/basipetal polar auxin transport の測定を [Lewis & Muday (2009), DOI:10.1038/nprot.2009.1](https://doi.org/10.1038/nprot.2009.1) に委ねる。**Chen2023 自体には、1値が何本の根をまとめたものか、根の年齢、採取区間、輸送を待った時間が明示されていない。** 従って n=3 を3本の根と呼ばず、原著の輸送 assay の3観測値と記す。参照 protocol の標準条件を、Chen で実施された条件として確定値にしない。同じ Methods にある protoplast assay の反復数を根の assay に移さない。

BA は併用された比較トレーサーである。IAA と BA は別の isotope・化学種なので、両者の生の dpm を同じ分子数として比較しない。Fig4A は WT と全体的 amiR の比較で、組織特異的 syn-tasi の方向性輸送を直接測ったパネルではない。輸送の減少と clock の変化は異なる測定からつながれた機構証拠であり、同一根の時系列相関ではない。

row 8 の平均、row 9 の `S.E.`、row 10 の著者検定は観測値から除外する。登録後の独立検算担当が、row 9 の IAA 2列は標準誤差、BA 2列は標本標準偏差と一致するというラベル上の不整合を確認した。この監査所見は原データの平均比を変更しない。元表を修正せず、BA の row 9 をそのまま確定した標準誤差として使用しない。この局所的な不整合から論文全体を否定しない。

放射能の到達は、根で化学形を維持した単一の IAA が一周した証拠ではない。Appendix S6 の D5-IAA 化学的完全性の検証は tobacco protoplast の export 試料に関するもので、Fig4A の根の到達試料にそのまま移せない。

### Fig4B/C：QC での合成誘導後の DR5:VENUS

4日齢の `pWOX5:XVE>>YUC1-2A-TAA1` に 5 µM estradiol を与え、0、7.5、9時間で伸長帯の表皮 DR5:VENUS を測った資料である。source の sheet は同じ `Figure 4`。

| 時間 | Control の範囲・値数 | amiR の範囲・値数 | 図説明の seedling 数 |
|---|---|---|---|
| 0 h | `H4:H43`、40 | `I4:I43`、40 | 各群少なくとも4 |
| 7.5 h | `J4:J73`、70 | `K4:K73`、70 | 各群少なくとも7 |
| 9 h | `L4:L143`、140 | `M4:M163`、160 | 各群少なくとも14 |

単位は A.U.。本文 PDF p8 の説明は、多数の蛍光値を複数の seedling から得たことを明記する。根 ID がないため、40–160の値を独立した根と数えず、10行ずつを同一根と仮定した cluster も作らない。時点ごとに同じ根を再撮影したかは source 表から同定できない。ZIP の6枚の CZI は各条件の提示画像であり、全 seedling の画像集合とは確認できていない。

この実験は、局所で合成を増やした後の離れた位置の応答を検出する。ただし DR5 転写応答は直接の流量計ではなく、既に存在する reporter の状態や局所応答も含む。7.5–9時間の応答を、時計の周期や IAA の帰還時間として採用しない。

## 4. 組織特異性と growth control が識別する範囲

Fig2 D/E/F は3回の独立した biological repeat と原著に記載されるが、公開表は repeat ごとの ID を持たない。Appendix S9 の根長は syn-tasi A の WT/line1/line5 が66/30/35値、syn-tasi B の WT/line2/line6 が66/33/29値で、説明の n と一致する。詳細範囲は manifest にある。これらを新たな clock 個体数に加算しない。

組織特異的介入と対照は、全身的な amiR の多面的影響だけで結果を説明する余地を小さくする。その一方で、**細胞生産が同じであること、戻り輸送だけが変わったこと、周期のすべてが輸送時間で決まることは、この構成からは確定しない。** 「gross growth の差が小さい」という著者の解釈と、独立に測定した細胞生産が一定という主張を分ける。

Fig2 と Fig6 は異なる抑制方法・比較群を用いた同じ論文内の証拠である。複数の機構的な確認として扱うが、別の研究室による独立再現、独立した二つの原著、同一根での全測定には数え替えない。

## 5. 小さな原資料上の不一致の扱い

- 周期・振幅の caption n と source 行数の違いは、E79 の推論単位に直接関わる。根数と対応が回復しない以上、根を単位とした CI や等価性の確定を行わない。
- Methods p12 の抽出図への参照は Appendix S7B/C となっているが、公開 Appendix S7（p11）は ABCB 発現パターンである。ROI・trace・振幅定義の実図は S4D–F（p6–7）に対応する。ここでは実物への参照を採用する。
- PBS density の Fig2B/Fig6F 説明は10日齢、一般的な PBS Methods は8日齢と記す。パネル固有の説明と Methods の差を残し、都合よく一方に統一しない。
- Fig4A row 9 の BA における `S.E.` 表示と算出量の差、および E80 登録票のパネル/sheet 表記は上記の通り。元資料・登録票の履歴を保持し、構造と解析対象を追記で明確にする。

## 6. 公開取得と再配布権の区別

[出版社ページ](https://link.springer.com/article/10.15252/embr.202256271) の Supplementary Information から付属資料へ通常の公開アクセスが成功した。Rights and permissions には著者の copyright が示されるが、この確認範囲で各生ファイルの再配布を許す明示的な CC 等のライセンスは確定していない。公開ダウンロード可能であることを、無制限な再配布の許可に置き換えない。

本文の Data availability は外部リポジトリへの deposit がないと述べるが、出版社が付属 source data を公開している事実と矛盾するものではない。本文・補足・source workbook の取得、再解析、原著実験の再現は別の段階である。今回は原資料の取得と構造監査までを担当した。効果量の再集計は登録済み E79/E80 の担当コードに委ねる。

## 7. 次の比較候補：GH32023（今回未再解析）

Wang et al. (2023), *GH3-mediated auxin inactivation attenuates multiple stages of lateral root development*, [DOI:10.1111/nph.19284](https://doi.org/10.1111/nph.19284) の [著者公開本文](https://backoffice.biblio.ugent.be/download/01HBBJMFJ3F8GJ69B3YSN7PYQG/01HBBKEEA6YHECM74PZGPTAEEY) と [補足](https://backoffice.biblio.ugent.be/download/01HBBJMFJ3F8GJ69B3YSN7PYQG/01HBBKP1D0TCDF3VJF5BPXNTN1) を取得した。Fig4 と補足 S7 は、DR5 の周期・振幅と meristem や成熟 cortex 細胞長を検討する次の候補になる。著者原稿 p18 の discussion は、gh3hex で高い DR5:LUC 振幅がないにもかかわらず PBS 形成の成功率が高いことから、レポーター振幅を PBS 形成の厳密な決定因子とはしない。この点は、Chen の輸送介入で見られる振幅低下を、あらゆる操作に共通する一定の振幅閾値へ一般化する際の制約である。GH3 は auxin の不活化を変える操作であり、戻り経路だけの介入ではない。本文・補足の読解に留め、今回新しい数値抽出・効果量再集計は行わず、E79/E80 の解析対象や新たに解析した独立生体研究数に加算しない。
